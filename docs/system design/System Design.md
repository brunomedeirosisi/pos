# System Design - Magazine Medeiros

## Objetivo

Padronizar a identidade visual da aplicacao com foco em clareza, consistencia e escalabilidade.

## Paleta

- Primaria: `#1F4EEB`
- Primaria clara: `#3D6FC2`
- Secundaria: `#7BA6D9`
- Neutro escuro: `#1F2937`
- Neutro medio: `#6B7280`
- Neutro claro: `#F1F5F9`
- Branco: `#FFFFFF`

## Cores funcionais

- Sucesso: `#22C55E`
- Atencao: `#F59E0B`
- Erro: `#EF4444`
- Info: `#0EA5E9`

## Tipografia

- Familia base: `Inter`
- Hierarquia:
  - H1: 32/40
  - H2: 24/32
  - H3: 18/28
  - H4: 16/24
  - Body 1: 14/22
  - Body 2: 13/20
  - Caption: 12/16

## Layout e espacamentos

- Sistema de espacamento: 8px
- Header: 64px
- Sidebar desktop: 280px
- Padding de pagina: 32px
- Gap entre cards: 24px
- Padding interno do card: 24px
- Radius base: 12px

## Elevacao

- Shadow 1: `0 1px 2px rgba(31, 45, 55, 0.06)`
- Shadow 2: `0 4px 12px rgba(31, 45, 55, 0.08)`
- Shadow 3: `0 12px 24px rgba(31, 45, 55, 0.12)`

## Componentes

- Botoes: primario, secundario, texto e icon-only, com estados default/hover/active/disabled.
- Inputs: estados default/focus/preenchido/erro.
- Badges: ativos e estados semanticos.
- Tabelas, cards e blocos de metricas com visual clean e alto contraste.

## Iconografia

- Estilo linear
- Grid 24px
- Espessura consistente

## Estrutura de interface

- Navegacao principal com sidebar vertical.
- Topbar para contexto de tela, idioma e usuario.
- Area de conteudo modular por cards.
